오늘도 헬스장에 왔다

세트 버튼만 눌러 빠르게 기록하는 오프라인 운동 일지

소개

오늘도 헬스장에 왔다는 기록하는 시간을 최대한 짧게 만든 운동 일지입니다. 회원가입이나 인터넷 연결 없이 앱을 열고 세트 버튼만 누르면 운동을 기록할 수 있습니다.

세트 완료와 함께 자동으로 시작되는 휴식 타이머, 나만의 운동 루틴, 55종의 기본 운동과 직접 추가하는 종목, 주별 볼륨·부위별 비중·추정 1RM 통계, 체중·골격근량·체지방률 기록을 지원합니다. 홈 화면 위젯과 운동 완료 공유 카드도 사용할 수 있습니다.

모든 운동 기록은 기기에 저장되며 JSON 파일로 백업하고 다른 기기에서 복원할 수 있습니다. 한국어와 영어, 라이트·다크·시스템 테마를 지원합니다.
