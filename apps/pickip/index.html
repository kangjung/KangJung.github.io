02두 가지 기준으로 찾기

닮은 사진과,
이름이 같은 사진.

찾는 기준을 섞지 않았어요. 화면이 비슷한 사진과 파일명이 같은 사진을 각각 따로 확인할 수 있습니다.

A

비슷한 사진

가까운 시간에 찍은 사진을 이미지 특징으로 비교해 묶어요. 최근 기간이나 시작일·종료일을 직접 지정하고, 일부를 남기거나 묶음 전체를 삭제 후보로 보낼 수 있어요.

최근 1개월최근 3개월전체 기간기간 직접 선택

모든 중복 파일을 찾는 기능은 아니며, 결과는 자동 삭제 판단이 아니라 직접 비교할 후보입니다.

B

같은 이름 사진

촬영 날짜나 폴더가 달라도 파일명이 정확히 같은 사진을 모아요. 비교 화면에서 폴더, 사진 크기, 촬영 시각과 용량을 함께 확인할 수 있어요.

파일명이 같아도 사진 내용이나 파일 데이터가 같다는 뜻은 아니에요.

03마지막 결정은 직접

선택은,
아직 삭제가 아니에요.

삭제 후보를 고르는 단계와 실제로 사진을 처리하는 단계를 나눴어요.

  • 묶음 전체도 후보로

    모두 필요 없다면 묶음 전체를 삭제 후보로 보낼 수 있어요. 최근 묶음 선택은 바로 취소할 수 있습니다.

  • 휴지통 또는 영구 삭제

    기본은 휴지통 이동이에요. 영구 삭제는 따로 선택하며, PicKip에서는 복구할 수 없어요.

  • 삭제 전 최종 확인

    후보를 다시 보고 남기기로 바꾼 뒤, 실제 처리할 사진만 직접 확정합니다.

04기기 안에서 처리

사진은 기기에.
결정은 나에게.

회원가입이나 사진 업로드 없이 시작해요. 비슷한 사진 분석, 파일명 확인, 남기기 기록과 정리 기록은 기기 안에서 처리하고 보관합니다.

앱은 Google AdMob 광고를 사용할 수 있습니다. 사진 처리와 별도로 광고 관련 데이터가 처리될 수 있으며, 자세한 내용은 앱의 개인정보 안내에서 확인할 수 있어요.

왼쪽으로 넘기면 바로 삭제되나요?

아니요. 삭제 후보로 표시할 뿐입니다. 마지막 확인 화면에서 직접 삭제를 결정하기 전에는 사진이 지워지지 않습니다.

비슷한 사진과 같은 이름 사진은 무엇이 다른가요?

비슷한 사진은 가까운 시간에 찍은 사진의 화면 구성을 비교합니다. 같은 이름 사진은 날짜와 폴더에 관계없이 파일명이 정확히 같은 사진을 모읍니다.

파일명이 같으면 완전히 같은 사진인가요?

아닙니다. 이름만 같고 내용은 다를 수 있습니다. PicKip에서 썸네일, 폴더, 크기, 촬영 시각과 용량을 확인한 뒤 직접 선택해 주세요.

비슷한 사진 묶음을 전부 정리할 수 있나요?

가능합니다. 묶음 전체를 삭제 후보로 보낸 뒤 선택을 취소할 수 있고, 실제 삭제 전에는 마지막 확인 화면을 한 번 더 거칩니다.

사진 접근 권한은 왜 필요한가요?

사진 목록, 촬영 시각, 파일명과 썸네일을 읽어 정리할 사진을 보여주기 위해 필요합니다. 일부 사진만 허용하면 허용된 사진만 검색하고 정리합니다.

아이폰에서도 사용할 수 있나요?

현재 PicKip은 Android 전용입니다. 앱은 한국어, 영어, 일본어를 지원합니다.
